regtable package

(Max) Hui Bai · R utilities · maxhuibai.com

This R package can put lm objects directly into a table that is compliant with the latest reporting practice in psych journals. In short, this package generates regression table from lm objects in R, compliant with the latest reporting practice for psych journals. It includes p value at 3 decimal points, 95% confidence interval, effect size in partial eta square, and standardized estimates.

https://github.com/baixx062/regtable

In case you are not familiar with R. Just type the following code to install and load it

library("devtools")
install_github("baixx062/regtable",force=TRUE)
library("regtable")

Here is an example for how to use it:

library(car)
a<-lm(mpg~cyl+disp+drat*wt,data=mtcars)
regtable(a,"tableresults.csv")
